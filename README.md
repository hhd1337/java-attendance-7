# java-attendance-precourse

## 기능 구현 목록

### 출석정보 로드 기능

- [x] src/main/resources/attendances.csv를 통해 크루별 출석부 리스트를 초기화한다.

### 메뉴 출력/분기/반복/종료 기능

- [x] 오늘 날짜와 함께 기능 메뉴를 출력한다.
- [x] 메뉴의 기능 하나가 끝나면 곧바로 기능목록 메뉴가 다시 출력된다. (Q를 입력 시 종료된다.)
- [x] 메뉴 입력을 받는다.
    - 예외) 메뉴에 없는 문자열일 경우

### 출석확인 기능

- [x] 닉네임을 입력받는다.
    - 예외1) 이름이 크루 목록에 없는 경우
- [x] 등교시간을 입력받는다.
    - 예외1) 시간을 포맷에 맞게 입력하지 않은 경우
    - 예외2) 등교일이 아닌 경우에 입력한 경우
- [x] 오늘 날짜, 요일, 출석시간, 출석결과(출석,지각,결석)를 출력한다.

### 출석 수정기능

- [x] 출석을 수정하려는 크루의 닉네임을 입력받는다.
    - 예외1) 이름이 크루 목록에 없는 경우
- [ ] 수정하려는 날짜를 입력받는다.
    - 예외1) 숫자가 아닌경우
    - 예외2) 1부터 해당 월의 마지막 일자 사이의 숫자가 아닐경우
- [ ] 해당 날짜의 변경할 시간을 입력받는다.
    - 예외1) 시간을 포맷에 맞게 입력하지 않은 경우
- [ ] 수정완료 메시지를 출력한다. (변경전의 날짜,요일,시간,출석상태 와 변경후 시간,출석상태 포함)

### 크루별 출석 기록 확인 기능

- [ ] 닉네임을 입력받는다.
    - 예외1) 이름이 크루 목록에 없는 경우
- [ ] 해당 크루의 이번 달 출석기록 목록과 총 출석,지각,결석 일수를 출력한다.
- [ ] 경고,면담,제적 대상자 여부를 출력한다.

### 제적 위험자 확인 기능

- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적 위험자 조회결과를 출력한다.
